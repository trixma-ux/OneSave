# Guide Utilisateur - OneSave

## Introduction

Bienvenue dans OneSave, l'application de gestion de projets pour le Campus Numérique Francophone (CNF). Ce guide vous aidera à utiliser toutes les fonctionnalités de l'application.

## Première Connexion

### Compte Administrateur par Défaut

Lors de la première installation, un compte administrateur est créé automatiquement :
- **Email** : admin@cnf.ci
- **Mot de passe** : admin123

⚠️ **Important** : Changez le mot de passe après la première connexion en allant dans votre profil.

### Créer un Nouveau Compte

1. Cliquez sur "Créer un compte" sur la page de connexion
2. Remplissez le formulaire :
   - Nom complet
   - Adresse email
   - Mot de passe (minimum 6 caractères)
   - Confirmation du mot de passe
3. Cliquez sur "S'inscrire"

## Navigation

### Menu Principal

Le menu principal se trouve sur le côté gauche de l'écran (ou en haut sur mobile) :

- **Tableau de bord** : Vue d'ensemble de vos projets et événements
- **Projets** : Gestion complète de vos projets
- **Événements** : Planification des rencontres et événements
- **Rapports** : Statistiques et analyses
- **Profil** : Gestion de votre compte

## Gestion des Projets

### Créer un Projet

1. Allez dans la section "Projets"
2. Cliquez sur "Nouveau projet"
3. Remplissez le formulaire :
   - **Titre** (obligatoire) : Nom du projet
   - **Description** : Détails du projet
   - **Date de début** (obligatoire) : Date de démarrage
   - **Date de fin** : Date de clôture prévue
   - **Statut** : Planifié, En cours, Terminé, Annulé
   - **Avancement** : Pourcentage de complétion (0-100%)
4. Cliquez sur "Créer"

### Modifier un Projet

1. Dans la liste des projets, cliquez sur l'icône de modification
2. Modifiez les informations souhaitées
3. Cliquez sur "Modifier"

### Supprimer un Projet

1. Dans la liste des projets, cliquez sur l'icône de suppression
2. Confirmez la suppression

⚠️ **Attention** : La suppression d'un projet supprime également tous les événements et modules associés.

### Détails d'un Projet

En cliquant sur un projet, vous accédez à sa page de détails où vous pouvez :
- Voir toutes les informations du projet
- Ajouter des événements liés au projet
- Ajouter un module spécifique (CLAC, IFADEM, GAF)
- Gérer les événements associés

## Gestion des Événements

### Créer un Événement

1. Allez dans la section "Événements"
2. Cliquez sur "Nouvel événement"
3. Remplissez le formulaire :
   - **Nom** (obligatoire) : Nom de l'événement
   - **Date et heure** (obligatoire) : Date et heure de l'événement
   - **Projet** (optionnel) : Lier l'événement à un projet
   - **Description** : Détails de l'événement
4. Cliquez sur "Créer"

### Modifier un Événement

1. Dans la liste des événements, cliquez sur l'icône de modification
2. Modifiez les informations souhaitées
3. Cliquez sur "Modifier"

### Supprimer un Événement

1. Dans la liste des événements, cliquez sur l'icône de suppression
2. Confirmez la suppression

## Modules Spécifiques

Les modules spécifiques permettent de catégoriser vos projets selon les programmes :
- **CLAC** : Centres de Lecture et d'Animation Culturelle
- **IFADEM** : Initiative francophone pour la formation à distance des maîtres
- **GAF** : (À définir selon vos besoins)

### Ajouter un Module à un Projet

1. Ouvrez la page de détails du projet
2. Dans la section "Module spécifique", cliquez sur "Ajouter"
3. Remplissez le formulaire :
   - **Nom du module** (obligatoire)
   - **Type de programme** (obligatoire) : CLAC, IFADEM ou GAF
   - **Détails** : Informations supplémentaires
4. Cliquez sur "Créer"

## Notifications

### Types de Notifications

L'application génère automatiquement des notifications pour :
- ⏰ **Échéances proches** : Projets se terminant dans les 3 prochains jours
- 🚨 **Projets en retard** : Projets dont la date de fin est dépassée
- 📅 **Événements à venir** : Événements dans les 24 prochaines heures

### Marquer une Notification comme Lue

Les notifications non lues sont affichées dans le tableau de bord. Pour les marquer comme lues :
1. Ouvrez la notification
2. Elle sera automatiquement marquée comme lue

## Rapports et Statistiques

### Tableau de Bord

Le tableau de bord affiche :
- Nombre total de projets
- Nombre d'événements à venir
- Nombre de projets en cours
- Nombre de projets en retard
- Avancement moyen des projets
- Liste des projets récents
- Liste des événements à venir

### Page Rapports

La page Rapports propose :
- **Répartition des projets par statut** : Graphique en camembert
- **Répartition des modules par type** : Graphique en camembert
- **Évolution des projets par mois** : Graphique en barres
- **Statistiques détaillées** : Cartes de résumé

## Gestion du Profil

### Modifier le Mot de Passe

1. Allez dans la section "Profil"
2. Cliquez sur "Changer le mot de passe"
3. Remplissez le formulaire :
   - **Ancien mot de passe** (obligatoire)
   - **Nouveau mot de passe** (obligatoire, minimum 6 caractères)
   - **Confirmer le nouveau mot de passe** (obligatoire)
4. Cliquez sur "Modifier"

### Informations du Profil

Dans la section "Profil", vous pouvez voir :
- Votre nom
- Votre adresse email
- Votre rôle (Administrateur ou Utilisateur)

## Mode Hors Ligne (PWA)

OneSave fonctionne comme une Progressive Web App (PWA) :
- L'application peut être installée sur votre appareil
- Fonctionne hors ligne pour consulter les données mises en cache
- Synchronisation automatique lors du retour en ligne

### Installer l'Application

1. Ouvrez OneSave dans votre navigateur
2. Cliquez sur l'icône d'installation dans la barre d'adresse
3. Suivez les instructions pour installer l'application

## Conseils et Bonnes Pratiques

### Gestion des Projets

- **Utilisez des titres clairs** : Facilite la recherche et l'identification
- **Mettez à jour l'avancement régulièrement** : Permet un suivi précis
- **Définissez des dates de fin réalistes** : Évite les projets en retard
- **Ajoutez des descriptions détaillées** : Améliore la compréhension du projet

### Gestion des Événements

- **Liez les événements aux projets** : Facilite l'organisation
- **Planifiez à l'avance** : Permet une meilleure préparation
- **Utilisez des descriptions** : Donne du contexte aux participants

### Notifications

- **Consultez régulièrement les notifications** : Ne manquez pas les échéances importantes
- **Marquez les notifications comme lues** : Garde votre interface propre

## Résolution de Problèmes

### Je ne peux pas me connecter

1. Vérifiez votre email et mot de passe
2. Assurez-vous que le serveur est démarré
3. Vérifiez votre connexion internet (si en ligne)

### Les données ne se chargent pas

1. Actualisez la page (F5)
2. Vérifiez que le serveur est démarré
3. Vérifiez la console du navigateur pour les erreurs

### L'application ne fonctionne pas hors ligne

1. Assurez-vous d'avoir visité l'application au moins une fois en ligne
2. Vérifiez que le service worker est activé
3. Vérifiez les paramètres de votre navigateur
